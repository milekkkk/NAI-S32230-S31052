# Hex

Gra Hex w Pythonie. Grasz przeciwko AI, działającej na podstawie biblioteki easyAI

## Wymagania

Python 3
Bibloteka easyAI==2.0.12

## Uruchomienie

Pobierz repozytorium i otwórz folder projektu w PyCharmie.

Utwórz wirtualne środowisko Pythona (.venv) i ustaw je jako interpreter projektu.

Otwórz terminal w katalogu projektu i zainstaluj wymagane biblioteki:

python -m pip install -r requirements.txt

Uruchom plik main.py.

## Zasady

- Plansza ma 5 × 5 pól.
- Gracz gra `X` i łączy górę z dołem.
- Komputer gra `O` i łączy lewą stronę z prawą.
= Wugrywa gracz, który jako pierwszy połączy odpowiednie krawędzie planszy.
